项目：`~/222/codex/3d-mini-game-demo`，Vue3 + TS + Three.js + Vite 的等距中式建造小游戏。
全部几何/材质/天空/粒子/人物由代码生成，零外部模型与贴图。dev 端口 5274。

## 本轮修复（4 个 bug）

1. **河道/湖面渲染成纯黑块**（上一轮遗留，曾误判为贴图问题）
   - 真因：`scene.ts` 构造函数里水面用的是**内联 `new THREE.BoxGeometry(...)`**，
     没走 `buildings.ts` 的 `waterTileGeo()`（该函数内部套了 `withWhiteColor()`）。
     `matWater.vertexColors === true` 但几何体无 `color` 属性 → three 的
     `color_vertex` 分支乘上缺省常量 0 → 全黑。
   - 误判复盘：`B-transpOnly`（关掉 vertexColors）正常、`A-plainLambert`（开着 vertexColors）
     仍黑 —— 这个二分结果其实已经排除了贴图、指向 vertexColors，当时却归因到了 `texWater`。
   - 修法：改用 `waterTileGeo()`，并新增 `ensureInstanceAttrs(geo)` 兜底
     （缺 `color` 补全 1、缺 `aTag/aFlex/aLeaf` 补 0），cliff/water/dashes 统一过一遍。
   - **教训**：凡是配 `vertexColors: true` 材质的几何，一律不能内联裸 `BoxGeometry`。

2. **水面是白板不是水**
   - `sync()` 从没给水面写过 `instanceColor`，`vColor` 恒为几何纯白，材质 `color` 又是默认白。
   - 修法：`matWater` 显式 `color: new THREE.Color(PALETTE.water)`；`sync()` 里
     `this.water.setColorAt(nWater, _c.setScalar(this.seedTint[i]))` 叠逐格微差。

3. **四季切换不进 3D 场景**（隐藏很久，因为 vue-tsc 一直崩没暴露）
   - `scene.applySeason()` 只在构造函数里被调过一次；四季按钮和 `tick()` 自动换季
     只改了 `state.season`，3D 世界永远停在春天。
   - 修法：App.vue 加 `watch(() => state.season, (id) => scene?.applySeason(id))`，作为换季唯一出口。

4. **类型检查从未真正跑起来**
   - `typescript@7.0.2` 移除了 `./lib/tsc` 导出，`vue-tsc@3.3.13` 直接抛
     `ERR_PACKAGE_PATH_NOT_EXPORTED` → 所有类型错误被掩盖。
   - 修掉 3 处真实错误：`sky.ts` 解构 3 元组写了 4 个变量；`materials.ts` 的
     `as MeshLambertMaterial` 需经 `as unknown as`；App.vue 模板里**内联箭头事件处理器**
     （`@rotate="() => (state.rot = ...)"`）会让 vue-tsc 误加 `.value`，
     改成 `<script>` 里的具名函数 `onRotate/onReset` 即解。

## 验证方法（可复用）

- 截图/探针脚本在 `/tmp`（`shoot-town.cjs`、`fps-probe.cjs`），**不属于交付物**。
  Chromium 用 `~/Library/Caches/ms-playwright/chromium-1148/.../Chromium`；
  必须 `dangerouslyDisableSandbox: true` 才能起浏览器。
- 软渲染（swiftshader）与真 GPU 差 3 倍以上（17 FPS vs 60 FPS），
  **测性能必须走 `--use-angle=metal`**，否则数字毫无意义。
- 页面暴露两个 DEV 钩子：`window.__town`（TownScene）、
  `window.__game`（state/setSeason/seedTown/clearAll/place/removeAt/scene/stats）。
  脚本化验证四季与建造全走它们，比点坐标可靠。
- 合成 PointerEvent 测试点击建造时，要先 stub 掉 `canvas.setPointerCapture`
  （没有活跃指针会抛 NotFoundError）。
- **Bash 里的 `grep` 在这个环境不可靠**（对已知存在的串也返回空），一律用 Grep 工具。
